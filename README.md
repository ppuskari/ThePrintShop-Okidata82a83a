# The Print Shop – Okidata MICROLINE 82A/83A OkiGraph I Driver

Apple II printer-driver work for Brøderbund The Print Shop v2, targeting the Okidata MICROLINE 82A and 83A with OkiGraph I firmware.

This repository is being built from the original Print Shop v2 source interface and the independently reconstructed OkiGraph I protocol documented in `ppuskari/Okidata-Microline-82A-83A`.
